# پورتفولیوی شخصی دوزبانه (فارسی / انگلیسی)

سایت شخصی مدرن و تمیز برای GitHub Pages.

## ویژگی‌ها
- دوزبانه (FA / EN) با دکمه تغییر زبان
- تم تاریک / روشن
- بخش‌ها: درباره من، تحصیلات، علایق، تماس
- کاملاً Responsive

## چگونه اطلاعات خود را تغییر دهید؟

### ۱. اسم
در فایل `script.js` داخل بخش `translations` این دو خط را عوض کنید:

```js
hero_name: "Your Full Name",   // هم در fa و هم در en
```

### ۲. لینک‌های سوشال و ایمیل
در فایل `index.html` لینک‌های GitHub، LinkedIn و ایمیل را پیدا کنید و عوض کنید.

### ۳. عکس پروفایل
عکس خود را با نام `profile.jpg` داخل پوشه `images/` قرار دهید.

### ۴. بقیه متن‌ها
تمام متن‌های فارسی و انگلیسی داخل فایل `script.js` در آبجکت `translations` هستند.  
هر چیزی را که می‌خواهید تغییر دهید، آنجا ویرایش کنید.

## دیپلوی روی GitHub Pages
1. ریپازیتوری با نام `username.github.io` بسازید.
2. فایل‌های این پوشه را در ریشه ریپازیتوری آپلود کنید.
3. Settings → Pages → Source: Deploy from a branch → main → / (root) → Save
